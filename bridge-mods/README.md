# Bridge mods

Our own small MO2 mods for IT NEVER GETS OLD WHEN SOMETHING BLOWS UP IN VR!, kept here as their source. Each
folder is copied as it is into `<list folder>\mods\` and switched on in the rung profiles (`tools/ladder_groups.py`
`BRIDGE_MODS` keeps them on in every rung, VR and flat alike). The base list's and TTWVR's own files are never edited.
Rows written before 2026-11-20 describe the list as it was then (named Atomic Fork VR).
